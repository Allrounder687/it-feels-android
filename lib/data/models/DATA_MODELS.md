# Data Models

This document outlines the core data models used within the PixelPlayer Flutter application. These models primarily represent entities retrieved from the JioSaavn API and are used throughout the application's various layers (data, services, providers, UI).

---

## 1. Song

Represents a single music track, containing essential metadata for playback and display.

**File:** `lib/data/models/song_model.dart`

### Fields:

*   `id` (String): A unique identifier for the song, often prefixed with 'saavn:'.
*   `saavnId` (String): The raw JioSaavn ID of the song. Derived from `id`.
*   `title` (String): The title of the song.
*   `artist` (String): The artist(s) of the song.
*   `album` (String): The album the song belongs to.
*   `duration` (int): The duration of the song in seconds.
*   `coverArt` (String): URL to the album cover artwork. The `fromJson` factory attempts to convert smaller image resolutions (150x150, 50x50) to 500x500 for higher quality display.
*   `streamUrl` (String?, nullable): The direct streaming URL for the song. This field is populated after decryption of `encryptedMediaUrl`.
*   `encryptedMediaUrl` (String?, nullable): The encrypted media URL received directly from the JioSaavn API. This URL needs to be decrypted to obtain the `streamUrl`.
*   `hasLyrics` (bool): Indicates whether lyrics are available for this song. Defaults to `false`.

### Factory Methods:

*   `Song.fromJson(Map<String, dynamic> json)`:
    *   **Purpose:** Constructs a `Song` object from a JSON map, typically received from the JioSaavn API.
    *   **Logic Highlights:**
        *   Handles various key names for `id`, `title`, `artist`, `album`, and `coverArt`.
        *   Extracts `saavnId` from `id` if prefixed.
        *   Transforms `coverArt` URLs to a higher resolution (500x500) if smaller resolutions are provided.
        *   Parses `artist` names from `more_info.artistMap.primary_artists` or `artist` fields.
        *   Applies `cleanText` utility to remove HTML entities from `title`, `artist`, and `album`.
        *   Determines `hasLyrics` from `more_info.has_lyrics`.

### Utility Methods:

*   `static String cleanText(String input)`:
    *   **Purpose:** A static helper method to clean up HTML entities (e.g., `&quot;`, `&amp;`) from input strings. Used during JSON parsing to ensure clean display names.

### Other Methods:

*   `Song copyWith({String? streamUrl, String? coverArt})`:
    *   **Purpose:** Creates a new `Song` instance, optionally overriding `streamUrl` or `coverArt` fields. This is useful for updating specific properties without re-creating the entire object, especially after stream URL decryption.

## 2. Playlist

Represents a collection of songs, which can be a playlist or an album.

**File:** `lib/data/models/song_model.dart` (defined in the same file as `Song`)

### Fields:

*   `id` (String): A unique identifier for the playlist/album.
*   `title` (String): The title of the playlist or album.
*   `coverArt` (String): URL to the cover artwork of the playlist/album. Similar to `Song`, attempts to upscale resolution.
*   `songCount` (int): The number of songs contained within the playlist/album.
*   `type` (String): Indicates the type of collection, typically 'playlist' or 'album'. Defaults to 'playlist'.

### Factory Methods:

*   `Playlist.fromJson(Map<String, dynamic> json)`:
    *   **Purpose:** Constructs a `Playlist` object from a JSON map, typically from the JioSaavn API.
    *   **Logic Highlights:**
        *   Handles various key names for `id`, `title`, `coverArt`, and `songCount`.
        *   Transforms `coverArt` URLs to a higher resolution (500x500).
        *   Applies `Song.cleanText` for title cleanup.

## 3. LyricLine

Represents a single line of synchronized lyrics, including its timestamp.

**File:** `lib/data/models/song_model.dart` (defined in the same file as `Song`)

### Fields:

*   `time` (Duration): The timestamp when this lyric line should appear, relative to the start of the song.
*   `text` (String): The actual text content of the lyric line.

### Constructor:

*   `LyricLine({required this.time, required this.text})`:
    *   A simple constructor to create a `LyricLine` instance. These objects are typically generated by the `LrcParser` from `.lrc` file content.
