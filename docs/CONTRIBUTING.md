# Contributing Guidelines

Thank you for contributing to **PixelPlayer Flutter (JioSaavn Edition)**!

## How to Contribute

1. **Fork & Clone** the repository.
2. Create a feature branch: `git checkout -b feature/amazing-feature`.
3. Ensure code conforms to Dart / Flutter conventions:
   - Run `flutter analyze` to check for lints and static errors.
   - Format code using `dart format .`.
4. Commit your changes with clear commit messages.
5. Submit a Pull Request.

## Code Conventions
- Follow official Flutter & Dart formatting standards.
- Keep widget build methods clean and modularized.
- Maintain test coverage for API parsing and stream decryption.
